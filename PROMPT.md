# compeye studio — задача для Cursor

## Что строим
Веб-конструктор для генерации TikTok-карточек и обложек в стиле бренда **compeye.app**
(competitive intelligence для SaaS). Пользователь редактирует текст/цвета, загружает
скриншот конкурента, и **скачивает готовый PNG 1080×1350** (формат TikTok-карусели).
Деплой на **Vercel**.

В репозитории уже есть `index.html` — это рабочий прототип со всей вёрсткой, стилями
и логикой экспорта. Используй его как источник истины для дизайна. Твоя задача —
превратить его в нормальное Next.js-приложение с компонентами и состоянием.

## Стек
- **Next.js 14** (App Router) + **TypeScript**
- **Tailwind CSS** для UI-панели (вёрстку самих карточек оставь на отдельных CSS-модулях
  или styled JSX — важно сохранить пиксельные размеры из прототипа)
- Экспорт PNG: **`html-to-image`** (`toPng`) — предпочесть его html2canvas, он точнее с
  кастомными шрифтами и тенями. Запасной вариант — `html2canvas`.
- Шрифты: **JetBrains Mono** (тело/моно) + **Space Grotesk** (заголовки) через `next/font/google`
  с `display: swap`. Подгружать локально, НЕ зависеть от сети при экспорте.
- Деплой: Vercel (zero-config для Next.js).

## Дизайн-система (взять из прототипа)
- Фон карточек: `#18181B`, фон UI-панели: `#0c0c0e`
- Акцент бренда: оранжевый `#e9960d` (иконка-«глаз», точки-сигналы)
- Акцент заголовка-ссылки: настраиваемый, дефолт оранжевый `#e9960d`
- Фон-текстура: звёздное поле (radial-gradients) + тёплое свечение снизу-слева
- Экспорт всегда **1080×1350 @ 2×** → итог 2160×2700

## Два режима (табы)

### 1) Card (карточка-слайд карусели)
Поля редактирования:
- **Badge** — сигнал-бейдж в углу скриншота (напр. `🔥 Trending on Reddit`, `📈 +14 hires`, `👀 Spotted on HN`)
- **Link / headline** — заголовок-ссылка, цвет настраивается
- **Description** — основной текст (моноширинный)
- **Footer right** — текст справа внизу (напр. `Save this post 🔖`)
- **Accent color** — цвет заголовка
- **Brand handle** — `compeye.app`
- **Screenshot upload** — картинка в белую рамку (drag&drop желательно)

Макет: скриншот в белой скруглённой рамке сверху → бейдж в правом верхнем углу рамки →
ссылка → описание → футер (слева бренд с иконкой-глазом, справа «save»).

### 2) Cover (обложка профиля / первый слайд)
Поля:
- **Title** — крупный заголовок, синтаксис `*слово*` подсвечивает слово зелёным
- **Subtitle** — подзаголовок
- **Bottom tag** — плашка внизу (дефолт = brand handle)

Макет: иконка-«глаз» крупно → большой заголовок → подзаголовок → тег внизу слева.

## Функционал, который надо добавить сверх прототипа
1. **Пресеты бейджей** — выпадающий список частых сигналов:
   `🔥 Trending on Reddit`, `👀 Spotted on HN`, `📈 +N hires this week`,
   `💰 New funding`, `🚀 New launch`, `⚠️ Pricing change`, `🆕 New feature` + free text.
2. **Мультислайд** — возможность собрать несколько карточек (массив слайдов в state),
   переключаться между ними и **скачать все разом в .zip** (`jszip` + `file-saver`).
   Это ключевая фича: карусель = много слайдов.
3. **Шаблон карусели**: первый слайд = Cover, остальные = Cards.
4. **Сохранение черновика** в `localStorage` (название проекта + слайды).
   ВАЖНО: localStorage только в реальном приложении на Vercel, не в среде-песочнице.
5. **Адаптивная панель**: на мобильном панель сверху, превью снизу.
6. **Кнопки**: «Download current PNG», «Download all (zip)».

## Критично для качества экспорта
- Рендерить экспортируемый узел в **реальном размере 1080×1350** (можно за экраном:
  `position:absolute; left:-99999px`), а превью масштабировать через `transform: scale()`.
  Если экспортировать масштабированный узел — получишь размытие.
- Дождаться загрузки шрифтов перед экспортом: `await document.fonts.ready`.
- `pixelRatio: 2` в `toPng`.
- Загруженные картинки — в base64 (FileReader), иначе CORS ломает canvas.

1. `npx create-next-app@latest` (или взять структуру выше)
2. Запушить в GitHub

4. Готово, получаешь `*.vercel.app` URL
